一次全面的稳定性与易用性更新：修复了崩溃、刷物品与多方块结构的一系列问题，补全英文本地化，并为每台设备加上了护目镜说明与搭建提示。

Create 仅支持 6.0.x 神秘时代 0.3.0-port.279 已验证 NeoForge 1.21.1 旧存档可直接升级
3崩溃修复
9刷物品 / 漏洞
20+机制修复
15+易用性改进

崩溃修复 重要

  • 神秘时代物品 ID 变化时，弹药数据导致所有世界都无法加载
  • 神秘时代缺少部分物品时，首次使用土豆加农炮导致服务器崩溃
  • 炼狱锅炉成型中途出错后，此后所有多方块结构都无法再拆解

刷物品 / 漏洞修复

  • 普通土豆加农炮也能 100% 回收弹药 → 现仅高压发射器的专属弹药可回收
  • 高压发射器带“土豆回收”附魔时一发掉两份弹药
  • 打碎锅炉观察窗白得一个物品，且结构留下破洞
  • 拆解锅炉时进阶炼金构材 / 进阶炼金炉被降级 → 现按原方块还原
  • 用流动岩浆搭锅炉，拆解后变成岩浆源
  • 涡轮机放在锅炉 4 格内（不贴着）也有满功率 → 现必须紧贴
  • 往锅炉里灌岩浆也能驱动涡轮机 → 现必须是水
  • 奥术工作台居中配方会吞掉图案外的多余材料
  • 居中配方现在需要先完成对应研究

多方块结构

  • 两台离心机 / 锅炉相邻时，拆一台却拆掉了另一台
  • 拆解后旧方块实体残留，原位重建的结构工作异常
  • 建在坐标 (0, 0, 0) 的结构永远拆不掉
  • 爆炸炸掉多个部件时重复拆解；拆解不再覆盖玩家后放的方块
  • 部件不能再被活塞、Create 装置推走或带走
  • 领地保护插件现在可以拦截法杖成型

大型奥法离心机

  • 不再吞掉原初源质（直接拒收）
  • 完成后不再卡在“离心中”
  • 输入口只从朝外一面抽源质

炼狱锅炉

  • 护目镜热量等级显示正确
  • 超频应力按实际引擎数计算
  • 没有引擎时不再消耗 Vis

动力设备

  • 傀儡动力 / 红石发动机：贴着传动轴放置时自动对齐输出轴
  • 扳手翻转：每台设备各自反转，齿轮啮合的设备不再爆转
  • 红石发动机：蓝图炮 / 指令放置也读取信号；加入防抖，红石时钟不再弹掉方块
  • 奥法涡轮机：生存破坏必定掉落；读档不再短暂超载；性能大幅优化

高压动力发射器

  • 副手持发射器时，主手土豆加农炮不再被一起加速
  • 读档后飞行中的弹体不会被再加速一次
  • 爆炸、雷击记在射手名下，击杀正常计分
  • 猪灵仇恨效果现在真正生效
  • 背包里有一颗铁粒时，土豆加农炮不再完全无法开火

物品与村民

  • 涅里伊德之庇：加上耐久（275，与神秘头盔一致），可附魔头盔附魔
  • 揭示之工程师护目镜：可以戴在 Curios 头部饰品栏
  • 村民不再生成空交易，打开交易界面不会再被踢出服务器

易用性 新

  • 结构搭错会提示错在哪：法杖点离合器 / 动力轴承 / 守卫者玻璃，提示“(x, y, z) 处应为 XXX”
  • 护目镜信息：离心机进度与状态、锅炉火源质与 Vis 加热时间、红石发动机信号强度、涡轮机未工作原因、傀儡转向
  • 物品提示：红石发动机说明信号与转速的对应关系，涡轮机说明需紧贴锅炉
  • 英文本地化补全，英文客户端不再显示中文
  • 扳手翻转涡轮机显示顺 / 逆时针；法杖成型失败不再重复提示
  • 离心机悬浮标签全亮度显示，只在 16 格内出现
  • 研究图标不再黑紫；切换资源包后贴图不再错位
